## Documentation, tests, CI/tooling and accessibility

This bucket holds 103 verified findings about the repository's documentation, its test and invariant coverage, the CI and `just` tooling, and the frontend's accessibility. None is high severity; 31 are medium and 72 are low. Two pairs describe the same defect at the same file and are merged below (F313 with F362, F014 with F245), so the section has 101 entries. The medium items cluster in three places: architecture docs that now contradict AGENTS.md and the code, mutation-heavy surfaces with no behavioural test, and ARIA state that is conveyed by a CSS class alone.
